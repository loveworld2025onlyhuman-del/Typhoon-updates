# 風嶼 WIND ISLAND｜作業使用說明

1. 解壓縮作業包，雙擊 index.html 即可操作，無需安裝套件或連線。
2. index.html 為單檔完整應用；review.html 為審查報告；pointout.html 為程式碼解析；source.html 為跳行原始碼。
3. response.md 是工程說明，check.md 是 100 分制自評表。審查頁可用列印另存 PDF。
4. 提交截圖請使用附帶的「01-作品全螢幕.png」及「03-審查報告.png」。需要顯示整個桌面時，請在自己的裝置將瀏覽器全螢幕後重新截圖。
5. 網頁「儲存畫面」匯出的是地圖情境 PNG，並非完整工作台。

## GitHub Pages
作業截圖中的部署是推薦項目，本包未登入或代用你的 GitHub 帳號。
建立 Repository，把本資料夾內所有檔案上傳到根目錄（index.html 要在根目錄），進入 Settings → Pages，選 Deploy from a branch，Branch 選 main，資料夾選 / (root)，儲存後等待部署並開啟 GitHub 顯示的網址。可將網址附在課程繳交區。

## 限制與自評
本作為 CSS 3D 透視與純 SVG 教學模擬，不是精確 3D 地形或氣象預報。時間軸風雨數值無觀測依據。rAF 量測是影格間隔，不是 CPU 計算時間；未做人工 Performance trace 和音效聆聽。完整評分見 check.md，94/100 為條件式自評，非教師成績。

本作由 AI 協助生成與測試；請依課程規定揭露使用方式，並理解與實際操作後再繳交。
